Hướng Dẫn Triển Khai GitHub Pages

1. Tạo một repository mới trên GitHub (public).

2. Tải lên 4 file: index.html, style.css, data.js, app.js.

3. Vào Settings -> Pages của repository.

4. Tại mục Build and deployment, chọn Branch là main (hoặc master) và thư mục / (root), rồi nhấn Save.

5. Sau 1-2 phút, GitHub sẽ cung cấp link công khai cho bạn!
